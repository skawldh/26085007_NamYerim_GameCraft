## 2. 게임 컨셉

사람은 꿈을 품고 목표를 향해 나아갈 때 비로소 진정한 행복과 삶의 색채를 되찾을 수 있다.

게임의 핵심 메타포 — **빛의 조각 수집 = 무채색 회복 = 자아의 성장**.
플레이어는 처음 작고 반투명한 한 존재로서 어두운 심연에 떨어진 뒤, 달리며 "꿈의 조각(빛)"을 모아 세계를 다시 물들여 나간다. 4구간(늪지 동굴 → 용암 동굴 → 빌딩 숲 → 초원)을 지나면서 자아는 단단해지고, 어둠은 점차 색으로 채워진다. 마지막에 다시 받는 "10년 뒤의 편지"의 질문에, 플레이어는 직접 답을 적는다.
