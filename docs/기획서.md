# 개요

라틴어 *lūmen* — "빛, 명도, 눈빛". 어둠 속에서 다시 일어서는 자아의 여정을, 빛의 조각으로 무채색의 내면을 물들이는 2D 러닝 게임.

> **메시지**
> 사람은 꿈을 품고 목표를 향해 나아갈 때 비로소 진정한 행복과 삶의 색채를 되찾을 수 있다.

플레이어는 작고 반투명 한 존재로 어두운 심연에 떨어진 뒤, 달리며 **꿈의 조각(빛)** 을 모아 자아를 회복한다. 마지막엔 **"지금 너는 어떤 꿈을 꾸고 있어?"** 라는 10년 전의 질문에 직접 답하면서 엔딩으로 진입한다.

# 시스템 기획 내용

## 플레이 방식

- 플레이어는 화면 좌측에 고정, 배경과 장애물이 **오른쪽 → 왼쪽**으로 자동 스크롤.
- 4구간을 차례대로 통과하며 성장·채색·난이도가 함께 변화.
- 핵심 조작 3종(점프,더블 점프,슬라이드) + 엔딩 입력 1종.

### 조작 표

| 키 | 동작 | 회피 대상 | 비고 |
|---|---|---|---|
| Space | 점프 / 더블 점프 | 지상 장애물, 용암 지대, 구멍, 사냥 덫 | 공중에서 한 번 더 누르면 더블 점프 |
| ↓ | 슬라이드 | 1구간 회색 연기, 3구간 모래바람 | 누르고 있을 때만 |
| Enter | 답 입력 확정 | — | 엔딩 한정 |
| Any key | 컷 스킵 | — | 인트로 한정 |

### 점수

목숨 3개, 게임 오버시, 구간 시작점부터 재시작
// `점수 = 이동 거리 + 꿈의 조각 획득 수 × 가중치` (구간 계수 적용)
// 게임 오버 시점까지의 결과 점수 표시 후 **구간 시작점**부터 재시작 가능 (전체 재시작 X)

## 스테이지 구성

4구간, 명시적 스테이지 번호 대신 **난이도 곡선 + 배경 분위기 전환** 으로 콘텐츠 확장. 각 구간은 학습 곡선상 한 가지 조작의 "수련 구간" 역할.

| 구간 | 테마 | 색 | 주 장애물 | 학습 조작 | 핵심 메시지 |
|---|---|---|---|---|---|
| 1. 늪지 동굴 | 축축하고 눅눅한 동굴, 위는 뿌연 연기 | 차콜·무채색 | 지상(덩쿨·가시) + 저천장(연기) | 점프·슬라이드 | "꿈도 두려움도 없는 막막함" |
| 2. 용암 동굴 | 천장 높아짐, 바닥 용암, | 회색+용암색 | 용암 지대 + 지상 | 더블 점프 | "꿈이 생겼기에 두려움도 생김 — 세상은 꿈이 있는 자에게 야박하다" |
| 3. 빌딩 숲 | 아포카립스 도시, 폐건물·전광판·우산 인파 | 뮤트 | 전광판 낱말(슬라이드 구간) + 고철·난간(지상) + 우산 인파(계단/점프) | 복합 | "현실 제약과 떄로는 밟고서라도 나아가야 한다" — 후반부 빌딩이 나무로 점진 변화 |
| 4. 초원 | 밝은 자연, 높은 하늘, 화사한 색체 | 파스텔+화사 | 구덩이·덫·매 | 전 조작 + 고속 대응 | "단단화된 자아 — 더 이상 남의 시선에 흔들리지 않는다" |

### 구간 전환 연출
1. 페이드 인/아웃 2~3초
2. 배경 + 팔레트 전환
3. **플레이어 성장 플래시**: 잠시 빛나며 투명도가 다음 단계로
4. 이동 속도 계단식 상승
5. (3→4) 3구간 후반 빌딩이 나무로 점진 변화 → 숲을 빠져나와 초원 진입

### 난이도 곡선
- 구간 내부는 완만한 상승, **구간 경계에서 계단식 점프**
- 스토리적 정당화: *"꿈에 가까워질수록 세상의 저항이 거세진다"*

## 캐릭터 모델

### 플레이어

| 항목 | 1구간 | 2구간 | 3구간 | 4구간 |
|---|---|---|---|---|
| 크기 배율 | 0.5× | 0.5× | 0.5× | 1.0× |
| 투명도 | 50% | 80% | 100% | 100% |
| 이동 속도 | 느린 걷기 | 조깅 | 달리기 | 전력 질주 |
| 형태 | 반투명 말랑 슬라임 | 색이 옅게 물듦 | 뚜렷한 형태 | 인간형 |

- 일러스트: **흰색 1등신** (코·입 없이 눈만 있는 미니멀 말랑 캐릭터)
- 말랑함 표현: 점프/착지 시 **squash & stretch** (스프라이트 납작/늘림)
- 달리기 애니메이션 재생 속도는 이동 속도에 비례 → "커지고 빨라지는" 체감 동기화

### NPC / 적 / 시트

- **지상 장애물**: 덩쿨·가시덤불 (1), 고철·난간 (3), 사냥용 덫 (4)
- **비행 장애물**: 전광판 낱말 (3), 반투명 우산 인파 (3), 매 (4)
- **저천장 해저드**: 회색 연기 (1)
- **구덩이**: 용암 지대 (2), 구멍 (4)
- **아이템 (꿈의 조각)**: 희미하게 반짝이는 빛. 부유 애니메이션, 획득 시 파티클 + 상승 음계 효과음

## UI 구성

### 메인 화면
- 우편함 + 플레이어 일러스트
- 메뉴: **게임 시작 / 방법 / 종료**

### 인트로
- `<10년 뒤 나에게>` 우편 표시
- 본문: 글씨 흐릿하게 블러된 이미지 → "지금 너는 어떤 꿈을 꾸고 있어?" 만 뚜렷하게
- 우편 수신 → 암흑 → 1인칭 심연 낙하 풍

### 인게임 HUD
- 좌상단: **점수, 목숨(하트 3/3)**
- 좌하단: **수집한 꿈의 조각 개수**
- 우상단: **현재 구간 표시** (1 / 2 / 3 / 4)

### 게임 오버
- 부딪힌 장애물 크게 표시 → 화면 무채색 복귀 → 결과 점수 → 재시작 버튼

### 엔딩 시퀀스
- 방 진입 → 커서 깜빡임 → 직접 타이핑 → "다시 걷는다" → 마지막 메시지
